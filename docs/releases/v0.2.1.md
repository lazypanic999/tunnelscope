# TunnelScope v0.2.1

First public alpha release of the Python command-line prototype.

## Highlights

- Bounded IPv4 UDP probes with optional Linux Don't Fragment mode, JSON evidence,
  and separate per-direction comparison.
- Receiver observation reports and `correlate` for matching individual probes.
  Run IDs and endpoint checks help catch incorrectly paired reports.
- `show` prints concise terminal tables for probe, correlation, bidirectional
  comparison and lab JSON reports.
- Reproducible Linux namespace labs for a direct MTU boundary, blocked PMTU
  feedback and a blocked acknowledgement return.
- Two-VM validation of successful delivery and receiver correlation in both
  directions.

## Known limits

Timeouts remain inconclusive without cooperating receiver or path evidence.
The CLI does not discover an exact end-to-end path MTU or prove a root cause on
an unknown network. The UDP protocol is unauthenticated and unencrypted; run
it only in a controlled environment. IPv6, VPN-specific, Kubernetes and 5G
workflows are not implemented.
