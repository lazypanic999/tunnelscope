# TunnelScope v0.2.2

Small maintenance release of the Python command-line prototype.

## Changes

- `tunnelscope show receiver.json` summarizes receiver observations by run ID
  and payload size, including local acknowledgement send results.
- Empty receiver reports render without an error.
- Correlation identifies receiver captures containing the selected sender run
  alongside other runs and shows the number of unmatched observations.

## Limits

A receiver observation proves arrival at that receiver, while a successful
acknowledgement send call only proves that its local socket accepted the reply.
Timeouts remain inconclusive without additional evidence. The tool does not
discover an exact end-to-end path MTU or prove a root cause on an unknown
network. Use its unauthenticated protocol only in controlled environments.
