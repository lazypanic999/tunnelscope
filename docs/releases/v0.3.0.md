# TunnelScope v0.3.0

Alpha release of the Python CLI with more controlled network experiments and
a local report view.

## Highlights

- IPv6 UDP probes, cooperating receiver reports, run correlation and
  bidirectional comparisons. Linux `--dont-fragment` uses `IPV6_DONTFRAG` for
  IPv6 and retains IPv4 DF behavior.
- Bounded `--sweep START:STOP:STEP` payload-size grids (at most 16 sizes).
- Reproducible network namespace labs for a known IPv6 link boundary and a
  VXLAN overlay boundary, both checked in each direction.
- `tunnelscope html report.json --output report.html` creates a searchable
  local report view. The report content remains in the generated HTML.
- VPN and Kubernetes pod workflow guidance. Those two deployment types are
  documented but have not been validated on a real deployment.

## Known limits

The tool does not discover an exact end-to-end path MTU or prove a root cause
on an unknown network. A timeout remains inconclusive without additional
receiver or path evidence. The UDP protocol is unauthenticated and unencrypted;
use it only in a controlled environment. The HTML view fetches the project
logo from GitHub when online, but does not send the report to a service.
