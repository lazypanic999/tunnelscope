# TunnelScope v0.4.0

Alpha release focused on easier first use and portable reports.

## Highlights

- Generated HTML reports embed the project logo and work without a network
  connection or extra files. Search now shows the number of matching rows and
  a message when nothing matches.
- The README has a short path from installation to a local probe and HTML
  report.
- `tunnelscope --version` shows the installed CLI version.
- `html`, `combine` and `correlate` reject an output path that points to an
  input report, preventing accidental overwrite.

## Known limits

TunnelScope does not discover an exact end-to-end path MTU or prove a root
cause on an unknown network. A timeout remains inconclusive without more
receiver or path evidence. Its UDP protocol is unauthenticated and
unencrypted; use it only in a controlled environment. Real VPN and Kubernetes
workflows remain documented but unvalidated on a deployment.
