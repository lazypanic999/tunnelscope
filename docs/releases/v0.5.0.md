# TunnelScope v0.5.0

Alpha release focused on bounded payload-size evidence and maintainable modules.

## Highlights

- `tunnelscope search HOST --min MIN --max MAX` performs a bounded adaptive
  search using repeated Linux no-fragment UDP probes. It preserves individual
  attempts and adds `summary.search` to the existing schema-version-1 report.
- `show` and offline HTML reports display the search assessment and observed
  interval. Correlation and bidirectional combination accept search reports as
  ordinary probe reports.
- The implementation is split into network, reports, search and view modules
  under `tunnelscope_core`. Existing `tunnelscope.py` and `tunnelscope_view.py`
  imports and the installed CLI remain available.
- Isolated Linux labs validate IPv4 and IPv6 adjacent payload intervals in
  both directions. Blocked-ICMP and blocked-ACK labs remain inconclusive.
  See the [validation record](../validation/size-search.md).

## Limits

An adjacent observed interval is not an exact end-to-end path MTU. A timeout,
mixed results or socket error stops the search without a boundary claim.
Receiver acknowledgements are small, so reverse delivery needs a separate
experiment. The protocol remains unauthenticated and unencrypted; use it only
in controlled labs. Real VPN and Kubernetes deployment validation remains open.
