# TunnelScope v0.7.1

Patch release for report sanitization, with documentation built from real
v0.7 lab output.

## Fixes

- `sanitize` now shifts timestamps written with a trailing `Z`
  (`2026-11-05T22:51:35Z`) and keeps that form. v0.7.0 recognized only
  `+00:00`-style offsets and left `Z` timestamps unchanged in the copy. If you
  shared reports sanitized with v0.7.0, check them for such fields; reports
  written by TunnelScope itself use `+00:00` and were shifted correctly.
- The sanitize guide notes that a four-part version string such as a kernel
  release `6.6.87.2` is also a valid IPv4 address and is replaced like one.

## Documentation

- The README shows unedited output from a recorded run of the
  [asymmetric return-path lab](../validation/asymmetric-return.md): 1400-byte
  probes reach the receiver while their same-sized replies are lost or
  rejected with `EMSGSIZE`, and an ordinary small ACK still returns. The run
  is checked in as `examples/asymmetric-return-v07.json`, and
  `scripts/build_v07_images.py` rebuilds the images from it.
- The README adds a short "Test the return direction" section, sized-reply
  rows in the evidence table and the asymmetric lab in the validation table.
- The HTML report guide uses a current screenshot.

## Install

```sh
python -m pip install --upgrade tunnelscope==0.7.1
tunnelscope --version
```

Report formats and command-line options are unchanged from v0.7.0. See the
[v0.7.0 notes](v0.7.0.md) for same-sized replies and sanitization.
