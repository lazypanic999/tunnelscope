# TunnelScope v0.8.1

Patch release that makes joined HTML reports readable and improves the package
listing.

## Changes

- Joined HTML tables (probe/receiver correlation and diagnosis with receiver
  evidence) put the evidence columns first: payload size, sender status,
  whether the receiver saw the probe, evidence case and, for sized replies,
  return evidence. Probe IDs show their first 8 characters and timestamps their
  UTC time of day; the full values are in each cell's tooltip and the row
  filter still matches them. In v0.8.0 these tables were about 2,200 pixels
  wide and the evidence columns were off screen. The report page is now up
  to 1,400 pixels wide. JSON reports are unchanged.
- PyPI metadata lists the supported operating systems and tested Python
  versions, networking topics, and links to the documentation, issues and
  release notes.
- The README image shows the joined HTML view of the recorded asymmetric
  return-path lab, and the README mentions Windows receivers and the IPv6 lab.

## Install

```sh
python -m pip install --upgrade tunnelscope==0.8.1
tunnelscope --version
```

Report formats and command-line options are unchanged from v0.8.0. See the
[v0.8.0 notes](v0.8.0.md) for Windows receivers, the IPv6 lab and field
reports.
