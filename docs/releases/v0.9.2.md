# TunnelScope v0.9.2

Patch release after [v0.9.1](v0.9.1.md), with diagnosis input validation,
Python 3.13 delivery coverage and retained native Windows evidence.

## Reject malformed diagnosis probe IDs cleanly

A JSON list or object used as a nested diagnosis `probe_id` previously
reached a cross-run dictionary lookup before the ordinary probe validator.
The CLI could raise an unhandled TypeError. It now rejects malformed row/ID
types before that lookup, with a short `Error:` and exit code 1. The
regression also checks null/numeric IDs, unchanged input files and absence
of both requested JSON and HTML outputs. Valid joins, full identifier checks
and conservative evidence cases are unchanged.

## Python 3.13 delivery checks

The Linux/Windows matrix now covers Python **3.10, 3.12 and 3.13**, preserving
the installed-command checks, isolated installed-package workflow,
unprivileged suite, Linux namespace labs and per-version artifacts. The
required `Delivery checks` aggregate still depends on every matrix job.
Dedicated OpenVPN checks retain their existing Python 3.10/3.12 matrix.

Thanks to [HarshRajSinghania](https://github.com/HarshRajSinghania) for

## Reproducible demo in source distributions

Source distributions now include the repository's Python helper scripts,
including `scripts/build_v09_demo.py`, its checked-in input fixture and
replay guide, and `scripts/write_lab_manifest.py`, which the retained tests
import. The v0.9.1 source archive omitted those two helpers. The publication
workflow now safely extracts the actual built source archive and runs its
unprivileged suite before uploading distributions for publishing. Optional
demo rebuilding still requires Pillow; the CLI has no third-party runtime
dependencies.

## Native Windows validation records

The new records were measured with **v0.9.1** and retain that producer value:

- [IPv4 host/guest path](../validation/windows-wsl2-receiver.md): 3/3 small
  ACKs, 6/6 sized replies and 8/8 diagnosis replies.
- [IPv6 link-local path](../validation/windows-wsl2-receiver-ipv6.md): the
  same successful counts, with endpoint-local zones explained.
- [Oversized Windows replies](../validation/windows-oversized-replies.md):
  1600-byte probes arrive and small ACKs return in both families, while
  same-sized sends fail locally with actual `WSAEMSGSIZE` (10040). Receiver
  correlation distinguishes that error from the sender's timeout.

These are two kernels on one physical host, using existing virtual networking
and MTU 1500 interfaces. No test-created firewall rule, route, MTU or access
change was needed. They do not establish an exact PMTU, capture fragments,
validate routed IPv6 or replace independent operator VPN evidence.

## Install and validation

```sh
python -m pip install --upgrade tunnelscope==0.9.2
tunnelscope --version
```

The suite has 139 tests. Native Windows/Python 3.10 and 3.13 passed with the
17 expected platform/opt-in skips; unprivileged Linux/Python 3.12 passed
with 11 privileged-lab skips. Hosted delivery, WireGuard and OpenVPN checks
passed for the diagnosis fix before merging. Schema version 1, the UDP wire
protocol and runtime dependencies are unchanged.
