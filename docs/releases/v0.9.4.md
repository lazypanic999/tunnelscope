# TunnelScope v0.9.4

Patch release after [v0.9.3](v0.9.3.md) for `tunnelscope show REPORT --format
markdown`. It makes the plain source readable again and stops report values
from becoming GitHub mentions, issue links or math when the summary is pasted
into an issue.

## GitHub mentions, references and math

v0.9.0 to v0.9.3 encoded report values as numeric character references.
GitHub decodes those references before it links `@mentions`, `#123` and
`GH-123` references and renders `$...$` math, so a report field such as
`@name` in a pasted summary still became a mention (and could notify that
user), `#12` became an issue link and `$x$` became inline math. A
zero-width space now follows `@`, `#` and `GH-` before a name or number and
precedes every `$`. GitHub's documented `\$` and the `&#36;` reference both
still rendered as math inside table cells, so neither is used.

If you pasted a v0.9.0–v0.9.3 summary whose fields contained `@`, `#` or `$`,
check that issue for unintended mentions or links.

## Readable plain source

The previous export encoded every punctuation character, so the source read
like `192&#46;0&#46;2&#46;1` and `sized&#95;reply&#95;returned`. Only
characters that can change rendering are now encoded: `|`, `` ` ``, `*`,
`[`, `]`, `<`, `&`, `\`, `~`, non-ASCII characters, underscores at word
boundaries, `://`, `www.` and colons that would form an emoji shortcode such
as `:abc:`. Addresses, timestamps and statuses appear as written. Truncated
probe IDs end in `...` and missing values show `-`, so the output stays
ASCII for redirected Windows consoles.

A copied value can contain the invisible zero-width space; the JSON report
keeps exact values. See [Markdown report export](../markdown-reports.md).

## Validation

A sample with hostile values in every row (mentions, issue and `GH-`
references, URLs, `www.`, email, emphasis, strikethrough, math, emoji
shortcodes including IPv6 hex groups, images, HTML and code) was rendered
through GitHub's Markdown API in the repository context: no links, images,
emoji, mentions, issue references, emphasis or code elements, or math, and
every cell displayed its original value. The 147-test suite passed on
Windows with Python 3.10 and 3.13 and on WSL2 with Python 3.12, and all
Linux/Windows delivery jobs and the WireGuard/OpenVPN checks passed for
[#69](https://github.com/lazypanic999/tunnelscope/pull/69).

## Install

```sh
python -m pip install --upgrade tunnelscope==0.9.4
tunnelscope --version
```

This patch changes no JSON schema, wire protocol, dependencies or network
behavior; the text and HTML views are unchanged.
