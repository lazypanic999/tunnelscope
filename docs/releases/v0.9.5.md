# TunnelScope v0.9.5

Patch release after [v0.9.4](v0.9.4.md) for offline report validation,
sanitization and output-file protection. There is no wire-protocol, JSON
schema, dependency or measurement change.

## Correlation input checks

Probe and run identifiers must contain exactly the expected number of
hexadecimal digits. Embedded spaces, tabs and line breaks are rejected;
uppercase hexadecimal identifiers remain accepted for compatibility.

Boolean `payload_bytes` values are rejected instead of being treated as
integers. Diagnosis receiver joins also reject probe IDs reused across
their three sender runs before building the run lookup. Valid integer
sizes, missing-kind legacy probe reports and existing report provenance
remain supported.

## Sanitization boundaries

IPv6 addresses followed by punctuation such as `fd00:77::1: timeout` are
recognized and replaced while preserving the punctuation. Existing
`if-N` and `host-N.example` labels in free text are reserved so generated
labels do not collide with them.

IPv4-mapped documentation addresses reserve their underlying IPv4 address.
This prevents a private address from receiving a placeholder already present
in the batch. Mapped-address formatting remains consistent on supported
Python versions.

`sanitize` creates JSON and HTML copies exclusively. If another process
creates an output after preflight, the command fails without overwriting
that file. A failed batch can leave copies it completed before the error;
the batch is not transactional.

Sanitization is still a best-effort replacement of recognized values.
Review arbitrary free text and filenames before sharing. A sanitization
block is metadata, not proof that every private identifier was removed.

## Install

```sh
python -m pip install --upgrade tunnelscope==0.9.5
tunnelscope --version
```

Existing lab and VM records keep their original producer versions. This
patch does not add independent operator evidence or establish a path MTU
from timeouts. See the [field report guide](../field-reports.md) to contribute
bounded, reviewed evidence from a path you are allowed to test.
