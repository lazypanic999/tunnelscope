# TunnelScope v0.9.6

Presentation patch after [v0.9.5](v0.9.5.md). There is no wire-protocol,
JSON schema, dependency or measurement change.

## HTML report

HTML views (`tunnelscope html REPORT` and `--html` on `correlate`) now follow the viewer's light or
dark system setting. Summaries sit in cards, the table header stays visible
while scrolling, and wide tables scroll inside their panel instead of
widening the page. A print stylesheet drops the filter box and colours.

Known status values (for example `timeout`, `receiver_reply_send_failed`,
`sized_reply_received`) are coloured green, amber or red by a short script
that matches exact cell text. The markup is unchanged, so the page reads
the same with scripts off and existing scripts that parse it keep working.

## Diagnosis table fix

Diagnosis reports gave every "DF vs permitted" row one empty trailing
cell, so those rows had seven cells under six headers. A new test renders
every example report and checks one cell per header.

## README

The README starts from the problem (ping and SSH work, a bulk copy over
the tunnel hangs) and what the tool records, with the release-by-release
notes moved behind one link. The report screenshot follows GitHub's light
or dark theme.

## Validation

169 tests passed on native Windows with Python 3.10 and 3.13 and on WSL
Ubuntu with Python 3.12. Light and dark screenshots of a correlation and a
diagnosis report were checked in headless Edge.

## Install

```sh
python -m pip install --upgrade tunnelscope==0.9.6
tunnelscope --version
```

This release adds no new field evidence. Reports from real VPN paths are
still the most useful contribution; see the
[field report guide](../field-reports.md).
