# TunnelScope v0.1 scope

v0.1 is an installable prototype of the existing Python CLI. It can be built
and installed locally; it is not yet published to a package index.

## Included

- A `tunnelscope` console command with `receive`, `probe` and `combine`.
- Bounded IPv4 UDP payload probes and small acknowledgements between controlled
  endpoints.
- Optional Linux Don't Fragment mode and explicit local `EMSGSIZE` reporting.
- JSON reports with per-size counts, source/interface snapshot, observations,
  tentative hypotheses and missing evidence.
- Separate direction reports that can be combined without treating either
  direction as proof of the other's behavior.
- Direct-link MTU boundary and blocked-feedback Linux namespace labs.
- A two-VM bidirectional delivery validation record.

## Outside v0.1

- Automatic discovery of an exact end-to-end path MTU or root cause.
- Automatic remote orchestration, authentication or encryption.
- IPv6, VPN-specific, Kubernetes or 5G tunnel workflows.
- A graphical interface and a published package-index release.

## Before a public release

The local wheel and source distribution must build and install cleanly on
supported Python versions. We also need to choose and add a project license,
confirm the package name and publish a release only after reviewing the
distribution metadata and contents. These decisions are separate from local
v0.1 packaging.
